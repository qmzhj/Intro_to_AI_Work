# Pandoc 模板配置步骤

## 方式一：用 LibreOffice（推荐，WSL 内可直接操作）

### 安装 LibreOffice
```bash
sudo apt install libreoffice -y
```

### 创建模板

用 LibreOffice Writer 新建一个空白文档，然后设置样式：

**设置默认样式（正文）：**
1. 菜单栏 → 样式 → 管理样式（或按 F11）
2. 右键点击"默认样式" → 修改
3. 字体标签页：中文设为"宋体"、字号"12pt"（小四）、颜色黑色
4. 字体效果标签页：斜体设为"无"
5. 缩进和间距标签页：首行缩进 0.75cm，行距 1.5 倍
6. 确定

**设置一级标题（Heading 1）：**
1. 样式面板中右键"标题 1" → 修改
2. 字体标签页：中文"宋体"、字号 22pt（二号）、黑色
3. 字体效果标签页：加粗保留，斜体设为"无"
4. 缩进和间距标签页：首行缩进 0（不缩进），行距 1.5 倍
5. 确定

**设置二级标题（Heading 2）：**
1. 样式面板中右键"标题 2" → 修改
2. 字体标签页：中文"宋体"、字号 18pt（小二）、黑色
3. 字体效果标签页：加粗保留，斜体设为"无"
4. 缩进和间距标签页：首行缩进 0（不缩进），行距 1.5 倍
5. 确定

**设置三级标题（Heading 3）：**
1. 样式面板中右键"标题 3" → 修改
2. 字体标签页：中文"宋体"、字号 13.5pt、黑色
3. 字体效果标签页：加粗保留，斜体设为"无"
4. 缩进和间距标签页：首行缩进 0.75cm（一个 Tab 的缩进量），行距 1.5 倍
5. 确定

保存为 `template.docx`（文件 → 另存为 → 选择 .docx 格式）。

## 方式二：用 Windows 上的 Word

打开 Word → 新建空白文档 → 开始 → 右键修改样式：

**修改正文样式（Normal）：**
1. 右键"正文"样式 → 修改
2. 字体：宋体、小四、黑色
3. 点击左下角"格式" → 段落：首行缩进 2 字符、行距 1.5 倍

**修改标题 1 样式：**
1. 右键"标题 1" → 修改
2. 字体：宋体、二号、黑色、加粗
3. 格式 → 段落：无缩进、行距 1.5 倍

**修改标题 2 样式：**
1. 右键"标题 2" → 修改
2. 字体：宋体、小二、黑色、加粗
3. 格式 → 段落：无缩进、行距 1.5 倍

**修改标题 3 样式：**
1. 右键"标题 3" → 修改
2. 字体：宋体、13.5pt、黑色、加粗
3. 格式 → 段落：首行缩进约 0.75cm、行距 1.5 倍

保存为 `template.docx`。

---

## 模板准备好后运行

```bash
cd /home/ylc/Intro_to_AI_Work/snake-ai/期末报告/

# 合并 markdown
cat section_1_2.md section_3.md section_4.md section_5_6.md > report_combined.md

# 转 Word
pandoc report_combined.md -o report.docx --reference-doc=template.docx
```

生成的 `report.docx` 里标题文字和正文的字体、字号、缩进、行距就全部按要求自动设好了。不过封面、页眉页脚还需要在 Word 里手动补充。
