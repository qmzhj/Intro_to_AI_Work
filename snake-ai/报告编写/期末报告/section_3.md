## 3 模型和算法

### 3.1 深度强化学习核心理论体系

#### 3.1.1 马尔可夫决策过程

马尔可夫决策过程（Markov Decision Process, MDP）是深度强化学习的核心理论框架，用于对序贯决策问题进行数学建模。一个标准的MDP由五元组 (S, A, P, R, gamma) 构成，其中 S 为状态空间，A 为动作空间，P(s'|s,a) 为状态转移概率，R(s,a) 为即时奖励函数，gamma 为折扣因子。MDP的核心特性是马尔可夫性，即下一时刻的状态 s_t+1 仅依赖于当前状态 s_t 和当前动作 a_t，与历史状态无关。

本项目将贪吃蛇游戏场景建模为MDP。状态空间 S 定义为 12x12 网格上的三通道图像表示，分别编码蛇身位置、食物位置和蛇头位置。动作空间 A 包含上下左右四个离散移动方向。奖励函数 R 根据智能体的行为输出即时奖励：吃到食物得 +30 分，撞墙或撞自身得 -20 分，每步有 -0.01 的微小惩罚以鼓励高效移动，同时根据蛇头与食物的距离变化给予额外奖励信号以引导寻食行为。状态转移概率由游戏环境的固定规则自动生成，无需人工建模。通过MDP建模，贪吃蛇的序贯决策过程被形式化为标准的强化学习问题，为后续算法训练奠定了理论基础。

#### 3.1.2 强化学习试错迭代与自我优化机制

强化学习的核心思想是智能体通过与环境的持续交互，在试错中学习最优策略。在每个时间步 t，智能体观察当前状态 s_t，根据策略 pi(a_t|s_t) 选择动作 a_t 并执行，环境返回即时奖励 r_t 和下一状态 s_t+1。智能体将交互经验 (s_t, a_t, r_t, s_t+1) 用于策略改进，如此循环迭代，逐步提升决策质量。这一过程的目标是找到最优策略 pi*，使得累积折扣回报 G_t = sum(gamma^k * r_t+k) 的期望最大化。

在本项目中，上述迭代过程体现为贪吃蛇智能体在仿真环境中的完整训练循环。智能体从完全的随机探索开始，通过持续试错逐步学习有效的寻食与避障策略，最终收敛到较优的决策策略。

### 3.2 DQN 算法核心原理与数学推导

#### 3.2.1 基础 Q-learning 算法原理

Q-learning 是一种基于值函数的 off-policy 强化学习算法，其核心是维护一个状态-动作值函数 Q(s,a)，用于评估在状态 s 下执行动作 a 后所能获得的期望累积奖励。最优Q函数 Q*(s,a) 满足 Bellman 最优方程：

Q*(s,a) = E[ r + gamma * max_a' Q*(s', a') ]

其中期望 E 对下一状态 s' 的分布求取。

Q-learning 通过迭代更新逼近最优Q函数，更新公式为：

Q(s_t,a_t) 赋值为 Q(s_t,a_t) + alpha * [ r_t + gamma * max_a' Q(s_t+1, a') - Q(s_t, a_t) ]

其中 alpha 为学习率，r_t + gamma * max_a' Q(s_t+1, a') 称为目标值（TD Target），与当前Q值的差值即为 TD 误差。

传统 Q-learning 使用表格存储所有状态-动作对的Q值，适用于状态空间离散且维度较低的场景。但在贪吃蛇游戏中，12x12 网格上的三通道图像状态空间是连续且高维的，无法用表格存储。因此需要引入深度神经网络对Q函数进行函数逼近，即深度Q网络。

#### 3.2.2 深度 Q 网络优化机制

深度Q网络（DQN）使用深度神经网络 Q(s,a;theta) 来逼近最优Q函数，其中 theta 为网络参数。DQN 引入两大核心机制来解决传统Q-learning与神经网络结合时的训练不稳定问题：

第一，经验回放机制。智能体与环境的每次交互样本 (s_t, a_t, r_t, s_t+1, done_t) 被存入经验回放池 D。训练时从回放池中随机采样小批量样本进行网络更新，而非使用连续的实时交互数据。这一机制打破了训练样本之间的时序相关性，减少了参数的剧烈震荡，同时提高了样本的利用效率。本项目采用容量为 50000 的经验回放池，每次训练从中随机采样 128 条样本。

第二，双网络更新机制。DQN 维护两个结构相同但参数更新方式不同的网络：在线网络 Q(s,a;theta) 和目标网络 Q(s,a;theta-)。在线网络每步都通过梯度下降更新参数，而目标网络每隔固定步数从在线网络复制参数。目标值计算使用目标网络：

y = r + gamma * max_a' Q(s', a'; theta-)

训练损失函数为预测Q值与目标值之间的均方误差：

L(theta) = E[ (y - Q(s,a;theta))^2 ]

本项目在标准 DQN 的基础上进一步实现了两种改进变体：Double DQN 和 Dueling DQN。Double DQN 将动作选择与动作评估解耦——用在线网络选择最优动作，用目标网络评估该动作的价值——从而有效缓解标准 DQN 中 Q 值过高估计的问题。Dueling DQN 则将Q值分解为状态价值 V(s) 和动作优势 A(s,a) 两部分，在动作价值相近的场景下能够更准确地估计状态价值，提升收敛效率。三种变体共享经验回放池和目标网络框架，通过 algo 参数在代码中统一切换。

### 3.3 PPO 算法原理

PPO（Proximal Policy Optimization）是一种基于策略梯度的 on-policy 强化学习算法，采用 Actor-Critic 架构。与 DQN 系列算法不同，PPO 直接优化策略函数而非值函数。

在 Actor-Critic 架构中，Actor 网络（策略网络）pi_theta(a|s) 输出动作的概率分布，Critic 网络 V_phi(s) 估计状态价值。本项目采用共享 CNN 骨干的 Actor-Critic 结构，两者共用底层的卷积特征提取层，在特征提取后分岔为 Actor 头和 Critic 头。

PPO 的核心创新在于裁剪目标函数，用于限制策略更新的步长，防止单次更新过大导致性能崩塌。PPO 的损失函数由三部分组成：

策略损失（Actor）采用裁剪后的替代目标。设重要性采样比率 r_t(theta) = pi_theta(a_t|s_t) / pi_theta_old(a_t|s_t)，代表新旧策略在动作 (s_t,a_t) 上的概率比值。策略损失取裁剪前后的较小值：

L_CLIP = E[ min( r_t * A_t, clip(r_t, 1-epsilon, 1+epsilon) * A_t ) ]

其中 epsilon 为裁剪范围（本项目设为 0.15），A_t 为优势函数估计。当 r_t 超出 [1-epsilon, 1+epsilon] 范围时，目标函数被裁剪，梯度不再传播，从而限制策略的更新幅度。

价值损失（Critic）采用均方误差：

L_VF = E[ (V_phi(s_t) - R_t)^2 ]

其中 R_t 为 t 时刻的累积折扣回报。

优势估计采用广义优势估计（GAE），在偏差与方差之间取得平衡。首先定义单步 TD 误差：

delta_t = r_t + gamma * V(s_t+1) * (1 - done_t) - V(s_t)

GAE 通过指数加权平均多步 TD 误差来计算优势：

A_t = delta_t + (gamma * lambda) * A_t+1

其中 lambda 为 GAE 参数（本项目设为 0.95）。当 lambda 接近 0 时退化为单步 TD 误差，方差小但偏差大；当 lambda 接近 1 时接近蒙特卡洛估计，偏差小但方差大。

总损失函数为上述三项的加权和：

L_PPO = L_CLIP + c1 * L_VF - c2 * H(pi_theta)

其中 H(pi_theta) 为策略熵，c2 为熵正则化系数（本项目设为 0.05）。熵正则化鼓励策略保持一定的随机性，防止过早陷入确定性策略而缺乏探索。

### 3.4 项目整体模型架构

#### 3.4.1 环境交互模块

环境交互模块（snake_env.py）是贪吃蛇仿真环境的核心实现，完全由本项目从零自主搭建，遵循 Gymnasium 环境接口规范。该模块定义了贪吃蛇游戏的全部规则与交互逻辑。

环境的状态表示采用三通道图像编码方式：第一通道编码蛇身位置（蛇身占据的格子设为 1，其余为 0），第二通道编码食物位置，第三通道编码蛇头位置。这种编码方式保留了网格的空间结构信息，适合卷积神经网络处理。动作空间为离散四方向（上、下、左、右），每个动作对应蛇头在网格中的移动方向。不合理的动作（如反向移动导致直接撞身）由环境自动处理为无效操作，不产生状态转移。

奖励函数由多分量组合而成：吃到食物获得 +30 奖励，引导智能体学习寻食行为；撞墙或撞自身获得 -20 惩罚，引导智能体学习避障行为；每步施加 -0.01 的微小惩罚，鼓励智能体以更少的步数到达食物。此外，根据蛇头与食物之间曼哈顿距离的变化给予额外奖励或惩罚，为智能体提供更密集的引导信号，缓解稀疏奖励问题。

环境模块同时承担数据录制的功能：当训练进行到特定回合时，环境将该回合每一步的蛇位置、食物位置、动作、奖励、分数等数据完整记录，为后续可视化回放提供原始数据。

#### 3.4.2 深度神经网络结构

本项目根据算法的不同需求，设计了三种神经网络结构。

DQN 系列（标准 DQN 和 Double DQN）使用标准 CNN 模型（cnn_model.py）：输入为 3x12x12 的三通道图像，经过一层 stride-2 的卷积层（输入 3 通道，输出 32 通道，卷积核 3x3），将空间分辨率压缩到 6x6；展平后经过两层全连接层（1152 维到 256 维到 4 维），最终输出四个动作的 Q 值。输出层不使用激活函数，直接输出原始 Q 值。

Dueling DQN 使用 Dueling CNN 模型（dueling_cnn_model.py）：在共享的卷积特征提取之后，网络分岔为两个分支——价值分支输出标量状态价值 V(s)，优势分支输出四个动作的优势值 A(s,a)，两者组合为 Q 值 Q(s,a) = V(s) + A(s,a) - mean(A(s,a))。这种结构在多个动作价值接近时，能够更稳定地估计状态价值。

PPO 使用 Actor-Critic 共享 CNN 模型（ac_shared_cnn_model.py）：采用三层卷积结构（通道数 3→32→64→64，每层后接 BatchNorm 和 ReLU），将 12x12 的输入逐步压缩到 3x3。展平后经过共享全连接层（576 维到 256 维），然后分岔为 Actor 头（256 维到 4 维，后接 Softmax 输出动作概率）和 Critic 头（256 维到 1 维，输出状态价值标量）。相较于 DQN 的单层卷积，PPO 的深层卷积结构具备更强的空间特征提取能力。

#### 3.4.3 训练流程设计

本项目的训练系统（train.py）根据算法的不同特性，设计了两种训练流程。

DQN 系列采用 off-policy 训练模式。在每个时间步，智能体根据 epsilon-greedy 策略选择动作——以概率 epsilon 随机选择动作，以概率 1-epsilon 选择当前Q值最大的动作。环境返回下一状态和即时奖励，交互样本存入经验回放池。当回放池中的样本数量达到批大小后，每次交互后都从回放池中随机采样一批样本进行网络更新，以最小化预测Q值与目标Q值的均方误差。在线网络每步更新，目标网络每固定步数（本项目为 300 步）同步一次在线网络参数。探索率 epsilon 从 1.0 开始指数衰减，训练后期稳定在 0.01，实现从广泛探索到充分利用的过渡。

PPO 采用 on-policy 训练模式。智能体在每个时间步通过 Actor-Critic 网络获取动作概率分布和状态价值，按概率采样动作并与环境交互，将状态、动作、奖励、对数概率、价值等数据存入轨迹缓冲区。每个 episode 结束时调用 GAE 计算优势函数和累积回报。当积累的 episode 数量达到更新频率（本项目为 3 个 episode）后，执行多 epoch 小批量更新（8 轮优化，每批 32 条样本），更新完成后清空缓冲区，收集新一轮训练数据。

### 3.5 模型训练、优化与可视化策略

#### 3.5.1 超参数调优策略

深度强化学习模型的训练效果高度依赖于超参数的配置。本项目针对贪吃蛇场景的特性，对 DQN 系列和 PPO 的核心超参数进行了分析调试，以下分别说明各参数的设置依据与作用原理。

---

**版本一：段落式**

学习率设为 5e-4，DQN 系列和 PPO 通用。这个取值在稳定性和收敛速度之间较为平衡，适合轻量化网络在 12×12 网格上的训练。

经验池容量 50000，主要考虑小网格下每局产生的数据量有限，这个容量足以保证样本多样性，又不至于占用过多内存。

批大小 DQN 用 128，PPO 用 32。DQN 的 off-policy 训练从大池子里采样，批大一点梯度更稳定；PPO 每轮收集的数据量本身就不大，批大小设太大会导致更新次数过少。

目标网络每 300 步同步一次。更新太频繁就跟单网络没区别，失去稳定的目标；太久不更新则目标值与当前估计偏差过大，梯度方向不准。

探索率从 1.0 指数衰减到 0.01。前期需要大量随机试探来积累经验，后期策略成形后逐步降低探索，让智能体更多依赖已学知识。

PPO 裁剪阈值 0.15，比论文常用的 0.2 略小。小网格场景下状态变化粒度较粗，策略更新不宜太激进。熵正则化系数 0.05，给探索留了点余地，防止策略太早定型。GAE lambda 0.95，偏向多步回报估计，偏差更小。

PPO 每收集 3 个 episode 做一次更新，每次在数据上跑 8 轮优化。更新太频繁则样本利用率低，太多轮又容易过拟合到当前批次。

梯度裁剪设到 1.0。训练中偶尔会出现异常 TD 误差导致梯度爆炸，裁剪 1.0 在保护网络参数的同时不影响正常更新。

#### 3.5.2 训练稳定性优化策略

除超参数配置外，本项目还从算法机制层面采用了多项措施保障训练稳定性。

对于 DQN 系列，经验回放机制通过随机采样打破了训练样本的时序相关性，减少了参数更新的方差。目标网络为 Q 值估计提供了稳定的优化基准，避免了单网络更新中"移动目标"问题。Double DQN 通过解耦动作选择与动作评估缓解了 Q 值过估计现象，Dueling DQN 则通过价值-优势分解减少了冗余估计误差。在探索策略方面，指数衰减的 epsilon 确保了从广泛探索到策略利用的平稳过渡。

对于 PPO，裁剪目标函数通过限制策略比率的变化范围，有效防止了单次更新过大导致的策略崩溃。GAE 在偏差与方差之间取得平衡，提供了稳定的优势估计。熵正则化鼓励策略保持一定的随机性，防止过早收敛到确定性策略。梯度裁剪作为安全机制，拦截了可能破坏网络参数的极端梯度。多 epoch 小批量更新在单批 on-policy 数据上进行充分优化，提升了样本利用效率。

#### 3.5.3 多算法训练协调策略

本项目在同一训练框架下协调四种算法的训练流程。train.py 通过 --algo 参数统一切换算法，启动时根据算法类型自动完成以下工作：加载对应的神经网络模型（标准 CNN、Dueling CNN 或 Actor-Critic 共享 CNN）、配置相应的训练模式（off-policy 或 on-policy）、应用各自适用的超参数（批大小 128 或 32、探索率衰减策略或 PPO 裁剪阈值等）。DQN 系列三种变体共享同一训练循环，仅在目标值计算方式上存在差异——标准 DQN 直接用目标网络的最大 Q 值，Double DQN 用在线网络选动作后用目标网络评估，Dueling DQN 则在网络结构层面将 Q 值分解为价值与优势两部分。PPO 则因其 on-policy 的训练特性，单独实现基于轨迹收集与多 epoch 更新的训练循环。

在训练过程中，框架统一管理所有与实验流程相关的辅助工作：每回合结束后将奖励和步数追加到 NumPy 数组中、定期保存最佳模型和最终模型、按固定间隔录制逐帧游戏数据、在终端输出训练进度和关键指标。所有输出按 算法名_时间戳 的命名规范自动归档到 experiments 目录下，保证了实验流程的规范性和可复现性。不同算法之间的训练互不干扰，可独立运行也可按顺序依次启动，为后续的横向对比分析提供了统一的数据基础。

#### 3.5.4 可视化策略

为直观展示智能体从随机试探到策略收敛的完整学习过程，本项目设计并实现了录制-回放分离的可视化方案。该方案的核心思路是将数据录制与画面渲染解耦：训练阶段每固定回合数（本项目设为 200 回合）记录一局游戏的逐帧数据，包括蛇的位置序列、食物位置、动作、奖励、分数以及网络的输出值（DQN 的四个 Q 值或 PPO 的四个动作概率），录制操作仅涉及数组拷贝与文件写入，对训练速度的影响可忽略不计。训练完成后，可视化程序读取这些录制数据，按训练顺序依次播放。

在界面设计上，采用三区布局：控制栏位于顶部，用于显示和调节播放状态；中部为各算法的游戏画面及其对应的个体训练曲线，多个算法并排展示、播放时保持同步；底部为所有算法的总训练曲线对比图。蛇头四个方向以半透明色块叠加显示 Q 值或动作概率的热力图，直观呈现智能体的决策偏好。可视化的具体实现过程与遇到的困难在第 4.4.3 节中详细展开。

### 3.6 项目实践层面的特点

结合本科课程项目定位与现有同类研究的主要局限，本项目在以下方面具有自身特点：

在多算法实现方面，本项目在同一框架下系统实现了四种主流深度强化学习算法——标准 DQN、Double DQN、Dueling DQN 和 PPO，涵盖了基于值函数的方法和基于策略梯度的方法两种技术路线。四种算法共享同一仿真环境和评价体系，为直观对比不同算法的特性差异提供了统一的实验平台。

在可视化分析方面，如 3.5.4 所述，本项目设计了录制-回放分离的可视化方案，配合多算法并排回放与 Q 值热力图显示，为观察智能体的学习过程和决策行为提供了直观的分析工具。

在实验体系方面，本项目在统一环境下完成四种算法的对比训练，从收敛速度、训练稳定性和最终性能等维度记录实验数据，为分析各算法在贪吃蛇场景下的表现建立了可复现的实验流程。
